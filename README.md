I’ve been working as a developer (mostly React, FastAPI, and PostgreSQL), but lately, I’ve been spending my nights diving into the AI rabbit hole. 🤖

Instead of just watching endless tutorials, I decided to build something small to actually see how LLMs behave.

I built a Prompt Engineering Playground using Python, Streamlit, and the Groq API.

The idea is simple: You ask one question, and the app answers it using 4 different prompting techniques side-by-side:
1️⃣ Zero-shot (Just the question)
2️⃣ Few-shot (Giving examples)
3️⃣ Chain-of-Thought (Asking it to think step-by-step)
4️⃣ Role-based (Giving it a persona)

My biggest "Aha!" moment?
I was genuinely surprised to see how much the output changed. When I used few-shot, the AI copied the exact short format of my examples. And when I told it "You are a senior software engineer with 10 years of experience," the depth and structure of the answer were completely different from a normal prompt.

It made me realize that AI isn't just about the model; it's about how you talk to it.

I know it's a small step, but building this from scratch helped me understand API integrations, system prompts, and token behaviors practically.
